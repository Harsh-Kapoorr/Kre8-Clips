# Kre8 Clips — Ship Plan (48h)

> **For Claude:** Use `${SUPERPOWERS_SKILLS_ROOT}/skills/collaboration/executing-plans/SKILL.md` to implement task-by-task.

**Goal:** Ship a fully functional Kre8 Clips web app with auth, polished UI, BYOK pricing, and a sticky signup mechanic.

**Architecture:**
- Next.js 16 app (existing) — add auth routes, middleware, paywall
- SQLite auth DB via `better-sqlite3` in API routes (no external DB, zero infra deps)
- JWT (access + refresh) in httpOnly cookies
- Feature-gated pipeline: unauthenticated users see landing + login; BYOK users get full access; paid tier unlocks managed API keys + billing
- Vercel-ready (no server-side websockets, SSE via router, job state in `.jobs/`)

**Tech Stack:**
- Next.js 16 + TypeScript + Framer Motion (existing)
- `better-sqlite3` for user/session DB
- `bcryptjs` for password hashing
- `jose` for JWT (Edge-compatible)
- Middleware for auth-gating and rate-limiting

### Steps

**Step 1: Create `backend/auth/db.ts`**
- Use `better-sqlite3` to create `data/kre8.db`
- Users table: `id, email, password_hash, name, plan, api_key_deepgram, api_key_gemini, created_at, updated_at`
- Sessions table: `id, user_id, refresh_token, expires_at, created_at`
- Functions: `createUser(email, passwordHash, name)`, `findUserByEmail(email)`, `createSession(userId, refreshToken)`, `findSession(token)`, `deleteSession(token)`, `deleteUserSessions(userId)`
- Initialize DB on first import

**Step 2: Create `backend/auth/password.ts`**
- `hashPassword(password): Promise<string>` using bcryptjs (cost 12)
- `verifyPassword(password, hash): Promise<boolean>`

**Step 3: Create `backend/auth/jwt.ts`**
- Access token: 15min, JWT with `{sub: userId, email, plan}`
- Refresh token: 7 days, opaque random string stored in DB sessions table
- `signAccessToken(user)`, `verifyAccessToken(token)`, `signRefreshToken()`, `createSessionToken(userId)`

**Step 4: Create API routes**

### Plans
```typescript
const PLANS = {
  free: {
    name: "Free",
    lifetime_clips: 1,       // 1 clip total, no credit card, signup required
    features: ["generate"],
    locked_after: true,    // account locked after 1 clip, must upgrade
  },
  byok: {
    name: "Bring Your Own Key",
    clips_per_month: 999,
    features: ["generate", "multi_ratio", "speaker_tracking", "captions"],
    requires: ["deepgram_key", "gemini_key"],  // user provides
  },
  pro: {
    name: "Pro",
    clips_per_month: 100,
    price_usd: 19,
    features: ["generate", "multi_ratio", "speaker_tracking", "captions", "api_access"],
  }
}
```

### Free Tier Flow
1. User signs up → account created, `plan: "free"`, `clips_used: 0`
2. User submits YouTube URL → pipeline runs, `clips_used` becomes 1
3. User tries to submit another URL → **locked**: banner says "You've used your free clip. Upgrade to Pro or BYOK to continue."
4. Upgrade button → pricing page
5. After upgrade (BYOK or Pro), `clips_used` counter resets / unlimited

### Steps

**Step 1: `backend/plans.ts`**
- Define plan constants and feature flags
- `getUserPlanFeatures(user): string[]`
- `canUseFeature(user, feature): boolean`

**Step 2: Middleware plan check**
- In `/api/jobs` POST: check if user has reached clips_per_month limit
- Count user's jobs this month from `.jobs/` dir + user metadata
- Return 402 if limit reached with message to upgrade

**Step 3: Account page**
- Show current plan
- For BYOK: input fields for Deepgram + Gemini API keys (stored in DB, used in pipeline)
- For Pro: upgrade button (future: Stripe checkout)

**Step 4: Pricing page**
- Clean 3-card pricing layout (Free / BYOK / Pro)
- Feature comparison table
- "Current plan" badge if logged in

**Step 2: Modify signup flow**

- After signup, redirect to `/` with a toast: "Welcome! You have 5 free clips."

**Step 3: Gate clip generation on credits**
